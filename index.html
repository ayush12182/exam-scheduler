1 Registration input

One student per line: S1,25CS2304,25CS2101,25CS2203 or S1: 25CS2304, 25CS2101. A header row starting with “Student” is skipped.

2 Registrations

StudentCourses R(s)

Dynamic update

Add a new student, or change an existing student’s courses. The conflict graph and timetable are regenerated automatically.

1 Graph input

Limits: 1 ≤ |V| ≤ 50 and 0 ≤ |E| ≤ 50. Self-loops, duplicate edges, unknown labels and over-limit input are rejected with a message — nothing is silently discarded.
